# Общая память двух сессий

Этот файл читают обе сессии Claude перед работой и обновляют в том же
пуше, где что-то сделали или оставили открытым. Правила работы — в
CLAUDE.md в корне.

## Состояние на 2026-09-29

- `main` — единственная ветка.
- Весь код v1.3.0 (группы серверов, профили правил, DNS по правилам,
  статистика, «Сети», hyroutectl, UDP для прокси, фрагменты UDP, остаток
  подписки, новая резервная копия, правило из соединения) — в `main`.
- Поверх него:
  - исправления по ревью: место правила из QUIC-соединения, пересечение
    правил со списками geosite/geoip (категории, поддомены, диапазоны
    IP), неполная статистика в резервной копии, поиск соединения без
    копирования журнала, `Rule.On()`;
  - проверка дублей серверов и правил (см. docs/GUIDE.md, «Дубли»);
  - статистика без сайтов (см. «Решения владельца»).
- Заметки к выпуску: docs/release-notes/v1.3.0.txt (дополнены дублями).
  Тег v1.3.0 ещё не ставился.

## Решения владельца

- **Статистика не хранит сайты.** Ни в каком режиме: режимы — «Включён» и
  «Выключен». Файлы с сайтами от прежних сборок чистятся при первом
  обращении к диску (stats: purgeSitesLocked, mode.json `noSites`). Сбор
  сайтов не возвращать.

## Открыто

- Проверка на Windows вручную: всё из v1.3.0 и дубли (импорт той же
  ссылки, редактор сервера, «дубль» в списке, редактор правил, «Добавить
  пачкой», «Создать правило» из «Соединений» при копии ниже).
- Kill switch при обновлении HyRoute: жалоба осталась, нужен
  `updater.log` с машины пользователя.
- AddConnRule перекомпилирует все правила около 8 раз за клик. Заметно
  только при сотнях правил; лечится одной компиляцией `indexed` на вызов.
- Дубли не проверяются: в «Правила текстом» режиме «Все правила» (там
  предупреждение «Лишнее»), в готовых схемах (ставятся наверх целиком по
  задумке), у сервера подписки, совпавшего с ручным (добавляется, но
  помечен «дубль»).
