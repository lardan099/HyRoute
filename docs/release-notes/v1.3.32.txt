HyRoute 1.3.32

- Серверы: кнопка «Проверить все» измеряет пинг всех серверов сразу. Число появляется в строке каждого сервера, а список встаёт по пингу: самые быстрые наверху, не ответившие — в конце. «Свой порядок» возвращает ваш порядок, щелчок по числу измеряет сервер заново. Пинг — время ответа на короткий запрос через сервер; полсотни серверов проверяются примерно за минуту. Пинг виден и в списке серверов панели у значка в трее.
- Серверы: длинная строка с названием и значками больше не растягивает страницу шире окна.
- Группы: если сервер VLESS не подключился при проверке, причина больше не называет Hysteria.
