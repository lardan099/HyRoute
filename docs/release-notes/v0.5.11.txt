HyRoute 0.5.11 — запасные серверы и трей

- У правил «через VPN» и у «Всё остальное» можно указать запасные серверы. Если сервер правила недоступен, новые соединения идут через первый доступный запасной; если недоступны все — соединение не проходит и напрямую не уходит. Запасные серверы держатся запущенными, поэтому переключение мгновенное, а когда основной сервер оживает, новые соединения возвращаются на него.
- В правилах текстом запасные пишутся цепочкой: «youtube.com -> DE -> NL» (или через запятую).
- В «Соединениях» соединение через запасной сервер помечено «(fallback)».
- HyRoute живёт в трее: крестик прячет окно, а программа продолжает работать (настройка «Кнопка × сворачивает HyRoute в трей» в «Настройки» → «Запуск»). Щелчок по значку открывает окно, правая кнопка — меню «Подключить/Отключить» и «Выход». Значок цветной, когда HyRoute подключён. При автозапуске HyRoute стартует сразу в трее.

Исправления надёжности и безопасности:
- Закрыта уязвимость повышения прав через журнал обновления. Папки данных HyRoute защищены от подмены ссылками, задача автозапуска регистрируется без временного файла.
- Kill switch: во время блокировки DNS и DHCP открыты только службам Windows, зашифрованный DNS Windows работает. Блок снимается при выключении Windows, а если он остался после сбоя, HyRoute сам покажет его после входа в систему.
- При подключении уже открытые соединения, которые по правилам должны идти через VPN, сбрасываются и переоткрываются через туннель, а не продолжают идти напрямую.
- После отказа движка HyRoute переподключается сам (до 3 раз за 10 минут).
- Если сервер пропал после подключения, соединения переходят на запасной.
- Локальный HTTP-прокси больше не обрывает соединения через 30 секунд. LAN-прокси нельзя открыть на порту 49152 и выше.
- Настройки, которые не удалось прочитать, больше не затираются значениями по умолчанию.
- Задача автозапуска теперь своя у каждого пользователя и работает с обычным приоритетом. Старая переносится сама.
- Повторный запуск HyRoute открывает окно уже работающей копии.
- Тема и выбранная страница один раз сбросятся: данные окна перенесены в защищённую папку.
