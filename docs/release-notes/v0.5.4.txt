HyRoute 0.5.4 — программы из запущенных

- В правиле программу можно выбрать из запущенных: начните вводить часть имени («tele», «disc», «steam») — появятся подходящие программы с их названиями; кнопка «Запущенные…» открывает полный список с поиском. В «Правилах текстом» имена программ тоже подсказываются.
