HyRoute 1.2.0 — порты, правила из соединений, статистика, резервная копия

Правила по портам:
- В правиле можно указать порт сервера: 22, «443, 8443» или диапазон 27000-27200, вместе с протоколом TCP или UDP. Например, SSH через один сервер, игра на своих UDP-портах через другой. Правило может состоять из одного порта: тогда оно действует на любую программу и сайт.
- В тексте правил: «ssh.exe -> DE | tcp 22», «game.exe -> NL | udp 27000-27200», «* -> напрямую | порт 25».
- «Проверить адрес» проверяет и порт: example.com:22. Конвертер ACL переносит порты из ACL Hysteria.

Правило из соединения:
- В «Соединениях» кнопка «Создать правило…» (или правая кнопка по строке): на всю программу, на сайт, на весь его домен, на готовый список, в котором он есть, на адрес или на порт. Дальше обычный редактор правила; новое правило встаёт первым.

Статистика:
- Новая страница «Статистика»: сколько трафика прошло через VPN за сегодня, неделю, месяц и год — по серверам и по программам. Трафик локальных прокси считается тоже.
- Записывается только объём. Какие сайты вы открывали, HyRoute не записывает нигде.

Резервная копия:
- «Настройки → Резервная копия»: все серверы, подписки, правила, прокси и настройки в один файл .hyroute, зашифрованный паролем. Из него HyRoute восстанавливается на другом компьютере или после переустановки Windows.
- Вариант «Только правила» — без серверов и паролей, его можно отдать другому человеку.

Локальные прокси:
- SOCKS5 теперь передаёт и UDP (UDP ASSOCIATE), если UDP работает на сервере прокси. Для прокси с доступом из локальной сети HyRoute открывает порт в брандмауэре и для UDP.
