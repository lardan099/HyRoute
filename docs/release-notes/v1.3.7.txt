HyRoute 1.3.7

HyRoute Server ставится одной командой:
- В релизе теперь есть готовая панель: для Linux (x86_64 и arm64) и для Windows. Собирать её из исходников больше не нужно.
- На Linux с systemd панель ставится и обновляется одной командой:
  curl -fsSL https://github.com/lardan099/HyRoute/releases/latest/download/install-server.sh | sudo sh
  Скрипт сверяет сборку с SHA256SUMS релиза, ставит службу и в конце пишет код первого запуска и команду SSH-туннеля, через который панель открывается в браузере. Подробности — в docs/SERVER_MANAGER.md, раздел «Установка».
- Служба панели работает в песочнице systemd: без особых прав root и без записи в системные каталоги.
