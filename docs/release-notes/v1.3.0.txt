HyRoute 1.3.0

Группы серверов:
- «Серверы» → «Группы»: несколько серверов под одним именем, например «Авто». Группа сама выбирает сервер для каждого нового соединения: первый работающий (с возвратом на первый), самый быстрый, по кругу, случайно или один и тот же для сайта. Задержка меряется раз в минуту; по желанию сервер, у которого подряд не открываются соединения, группа на минуту обходит.
- Группу можно выбрать везде, где выбирается сервер: в правиле, в «Всё остальное», среди запасных, в локальном прокси и как основной. В тексте правил: «-> группа:Авто, NL». Если не работает ни один сервер группы, соединение идёт через запасные или отклоняется, напрямую не уходит.

Правила по портам:
- Блок «Протокол и порты» в редакторе правила: порты через запятую, диапазоны через дефис, правило только по порту («TCP 22 → напрямую»). Подсказки про QUIC (в UDP 443 имени сайта нет) и про UDP-порты 49152–65535 без программы.
- «Проверить адрес»: поле «Порт» и выбор TCP/UDP. Конвертер ACL переносит порты так же, как их понимает Hysteria; строки «all» с портом становятся правилами по порту.
- Правила с портами и текст правил версии 1.2 читаются как были. Порт из одних запятых («порт ,») при вводе теперь ошибка, а не «любой порт»; уже сохранённое версией 1.2 такое правило работает как раньше.

Профили правил:
- Несколько наборов правил, например «Дом», «Работа», «Игры», и переключение между ними: кнопка «Профиль» на странице «Правила», список на главной, меню значка в трее. Переключение действует сразу для новых соединений; соединения через серверы, которые новому профилю не нужны, закрываются.
- Новый профиль — копией текущего, с пустого списка или из готовой схемы «Шаблонов». «Открыть без включения» правит профиль, не переключаясь на него. Сервер или группу, которые нужны хоть одному профилю, удалить нельзя.
- Пока профиль один, всё как раньше: файл профилей (rulesets.json) появляется со вторым профилем, а правила включённого профиля по-прежнему лежат в settings.json.

UDP через VPN:
- UDP-датаграммы, которые Windows разбила на IP-фрагменты, HyRoute теперь собирает и отправляет через VPN целиком. Раньше они терялись.
- Предел Hysteria посчитан точно: через VPN проходит до 4066 байт данных на IPv4-адрес и 4040 на IPv6. Датаграммы больше отбрасываются, и в «Соединениях» у потока видно, сколько их было.

Остаток трафика и срок подписки:
- Если сервис сообщает остаток трафика и срок (3x-ui, Marzban, Remnawave и другие панели), «Подписки» показывают их у каждой подписки: «Осталось 86 ГБ / 12 дней», полоса израсходованного и дата окончания.
- Когда трафика меньше 10 % или до конца срока меньше 3 дней, а также когда подписка закончилась, на главной появляется предупреждение с кнопками «Обновить» и «Скрыть», а у «Подписок» в меню — их число. HyRoute при этом ничего не отключает.
- Интервал обновления, который советует сервис, подставляется при добавлении подписки; ссылку на поддержку сервиса можно скопировать или открыть в браузере.

DNS по правилам:
- «Настройки» → «DNS» (режим «Для опытных»), всё выключено по умолчанию. «DNS по правилам»: имена сайтов, которые правила ведут через VPN, HyRoute разрешает через тот же сервер по DoH, заблокированные сразу получают отказ, остальные идут как раньше. Если VPN недоступен, имя не разрешается напрямую; для входа в Wi-Fi гостиницы или аэропорта на главной есть кнопка «Разрешить имена напрямую на 5 минут».
- «Шифровать прямые DNS-запросы» через Cloudflare, Google, Quad9, AdGuard, Яндекс или свой DoH/DoT. «Не давать браузерам обходить DNS» и «Отключать ECH» — чтобы правила для сайтов срабатывали и в браузерах со встроенным «безопасным DNS».
- «Проверить адрес» показывает, как разрешится имя; запросы, на которые ответил HyRoute, видны в «Соединениях» с фильтром «DNS-запросы».
