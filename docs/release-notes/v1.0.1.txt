HyRoute 1.0.1 — исправления и доработки

Маршрутизация:
- Chrome и Firefox больше не прячут от HyRoute имя сайта: правила по сайтам срабатывают там, где раньше решалось по «Всё остальное».
- IPv6-соединение, маршрут которого зависит от сайта, отклоняется сразу, и программа уходит на IPv4, а не теряет уже открытое соединение.
- Цепочка CNAME считается одним сайтом, записи DNS живут столько, сколько сказал сервер.
- UDP через недоступный сервер показывается в «Соединениях» как отклонённый.

Kill switch и запуск:
- Состояние kill switch видно на каждой странице: «Интернет закрыт» на боковой панели и плашка с кнопками.
- Отменённое выключение Windows больше не снимает блокировку насовсем.
- Окно открывается в Windows 11 с включённой «Защитой администратора».
- Автозапуск работает из папки с русскими буквами в пути.

Правила:
- Правка правил в одном окне больше не затирается сохранением в другом: устаревшая страница обновляется сама, а сохранение поверх изменённых правил отклоняется с понятным сообщением.
- «Правила текстом»: IPv6-адреса, пути в кавычках, имена со слешем и звёздочкой; окно не закрывается, если отпустить мышь за его краем.
- «Проверить адрес» понимает имя программы без .exe.
- Повторное применение шаблона не плодит дубли.

Серверы, подписки, прокси:
- В поле адреса сервера можно вставить host:порт.
- Подписка, в которой поменялись только имена серверов, не сдвигает откат. Откат баз правил закрепляет прежнюю версию.
- Локальные прокси: HTTP/1.0, Expect: 100-continue, сброс соединения доходит до программы.
- Окно обновления можно скрыть во время загрузки.

Безопасность:
- Программа без прав администратора больше не может заранее создать папку %ProgramData%\HyRoute\core или подменить временный конфиг Hysteria, которыми HyRoute пользуется с правами администратора.
- Базы правил и значок трея записываются без перехода по ссылкам.
- Посторонняя программа больше не может помешать подключению, заняв блокировку, которая не даёт двум копиям HyRoute перехватывать трафик одновременно.

Всего по итогам проверки кода v1.0.0 исправлено 135 проблем; выше перечислены те, что заметны пользователю.
