HyRoute 1.0.0 — первый стабильный выпуск

Windows-клиент Hysteria 2 с раздельной маршрутизацией по программам, сайтам, IP-адресам и спискам geosite/geoip.

В выпуск вошли запасные серверы, kill switch, локальные SOCKS5/HTTP-прокси, подписки, автозапуск, обновления с откатом и полный набор исправлений надёжности и безопасности.

Исправления надёжности и безопасности:
- Закрыта уязвимость повышения прав через журнал обновления. Папки данных HyRoute защищены от подмены ссылками, задача автозапуска регистрируется без временного файла.
- Kill switch: во время блокировки DNS и DHCP открыты только службам Windows, зашифрованный DNS Windows работает. Блок снимается при выключении Windows, а если он остался после сбоя, HyRoute сам покажет его после входа в систему. Для этого, пока kill switch включён, HyRoute держит задачу «HyRoute kill switch (<SID>)» в Планировщике заданий (только когда HyRoute лежит в защищённой папке Program Files).
- При подключении уже открытые соединения, которые по правилам должны идти через VPN, сбрасываются и переоткрываются через туннель, а не продолжают идти напрямую.
- После отказа движка HyRoute переподключается сам (до 3 раз за 10 минут).
- Если сервер пропал после подключения, соединения переходят на запасной.
- Локальный HTTP-прокси больше не обрывает соединения через 30 секунд. LAN-прокси нельзя открыть на порту 49152 и выше.
- Настройки, которые не удалось прочитать, больше не затираются значениями по умолчанию.
- Задача автозапуска теперь своя у каждого пользователя и работает с обычным приоритетом. Старая переносится сама.
- Повторный запуск HyRoute открывает окно уже работающей копии.
- Тема, цвет, открытая страница и режим «Скрыть данные» один раз вернутся к значениям по умолчанию: данные окна перенесены в защищённую папку %ProgramData%\HyRoute\webview. Прежнюю папку %APPDATA%\HyRoute\webview можно удалить.
