HyRoute 1.3.3

Расширение для браузера:
- Пошаговая настройка при первом запуске предлагает кнопку HyRoute в браузере: на шаге «Запуск» — галочка «Кнопка HyRoute в браузере» (если найден Chrome, Edge, Яндекс Браузер или другой браузер на Chromium), на шаге «Готово» — кнопки браузеров и три шага, чтобы её добавить.
- В простом режиме карточка «Настройки» → «Расширение для браузера» описывает расширение без технических подробностей.

Серверы с одинаковыми названиями:
- Когда серверы приходят из нескольких подписок с одинаковыми серверами, меню «Всегда через …» в «Соединениях» и списки выбора сервера делят их по подпискам, а не показывают подряд два одинаковых списка.
- Сервер, названный так же, как другой, подписан, откуда он («🇳🇱 NL · Сервис», «… · добавлен вручную»): в правилах, на главной, в «Проверить адрес», журнале, статистике и расширении для браузера.
