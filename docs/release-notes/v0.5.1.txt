HyRoute 0.5.1 — исправления безопасности

- hysteria.exe и драйвер WinDivert теперь запускаются не из папки программы, а из проверенной копии в папке, куда могут писать только администраторы. Файлы сверяются с контрольными суммами, зашитыми в HyRoute.exe; подменённый файл не запустится.
- Если HyRoute запущен не из Program Files (например, из «Загрузок»), на главной странице появится кнопка «Перенести»: HyRoute скопирует себя в Program Files, добавит ярлык в меню «Пуск» и перезапустится оттуда.
- Специально испорченный DNS-ответ больше не может уронить HyRoute (уязвимость в библиотеке разбора DNS, GO-2026-5942). Программа собрана на Go 1.27.1 с обновлёнными библиотеками; сборки проверяются govulncheck.
- Ошибка при обработке одного пакета теперь отбрасывает только этот пакет, а не снимает перехват целиком.
- Большие UDP-датаграммы, разбитые на IP-фрагменты, больше не уходят напрямую в обход правил «через VPN» и «блок».
- netsh и Проводник запускаются по полному пути.
- В предпросмотре подписки по http:// появилось предупреждение: токен в такой ссылке передаётся без шифрования.
- В README описано, от чего HyRoute не защищает и как его удалить.
