HyRoute 1.3.34

- Серверы: можно проверить пинг не всех серверов, а одной подписки. Рядом с поиском появился выбор «Все серверы» / подписка / «Добавлены вручную»: список показывает только выбранное, и кнопка «Проверить показанные» измеряет только эти серверы. В компактном списке у заголовка каждой подписки есть ссылка «Проверить». С поиском кнопка тоже проверяет только найденные.
- Серверы: вместо пары «Свой порядок» / «По пингу» — одна кнопка «По пингу», которая нажимается и отжимается.
