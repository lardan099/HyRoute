HyRoute 1.3.8

Панель для своих серверов прямо из HyRoute:
- «Серверы» → «Открыть панель» запускает HyRoute Server на этом компьютере и открывает его в браузере. Панель ставит Hysteria на ваш VPS по SSH, настраивает её и выдаёт ссылки для HyRoute.
- Панель приходит в архиве HyRoute и обновляется вместе с ним: скачивать Go и собирать ничего не нужно. Работает без прав администратора, в свёрнутом окне «HyRoute Server»; закрыть окно — остановить панель.
- При первом запуске код уже подставлен: остаётся придумать имя и пароль владельца.
