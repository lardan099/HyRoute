HyRoute 0.5.8 — автозапуск

- Настройки → Запуск → «Запускать HyRoute при входе в Windows». HyRoute стартует свёрнутым через задачу в Планировщике заданий, поэтому Windows не спрашивает разрешения администратора при каждом входе. Доступно, когда HyRoute лежит в Program Files: запускать с правами администратора программу из папки, куда может писать любая программа, небезопасно.
- «Подключаться сразу после запуска»: вместе с автозапуском HyRoute сам восстанавливает подключение после перезагрузки, а с ним и kill switch, и локальные прокси.
