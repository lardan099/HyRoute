HyRoute 0.5.5 — локальные прокси

- Новый раздел «Прокси»: порт на этом компьютере для программ, в которых можно указать прокси (терминалы бирж, браузеры, боты). Каждый прокси ведёт через свой сервер, независимо от правил: например, терминал Binance через Японию на 10801, Bybit через Сингапур на 10802. Один порт понимает и SOCKS5, и HTTP.
- Логин и пароль по желанию, кнопка «Придумать» создаёт пароль. Пароль хранится зашифрованным, как пароли серверов.
- Прокси может быть доступен из локальной сети (телефон, другой компьютер) — только с паролем и только в домашней или рабочей сети Windows.
- Прокси работают, пока HyRoute подключён; нужный сервер запускается сам, даже если его не использует ни одно правило. Для каждого прокси видно число соединений и трафик, адреса копируются в виде socks5://… и http://….
- UDP через локальный прокси не передаётся (SOCKS5 UDP ASSOCIATE отклоняется).
