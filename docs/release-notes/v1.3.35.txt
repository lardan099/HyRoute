HyRoute 1.3.35

- Расширение сохраняет, меняет и убирает правила для браузера, из которого его открыли. Импорт SwitchyOmega и ZeroOmega просит выбрать браузер. Такие правила больше не перехватывают трафик OBS и других программ.
- При первом запуске после обновления HyRoute автоматически добавляет Google Chrome в существующие доменные правила без программы во всех профилях. Исходные правила сохраняются в `browser-rules-before-update.hyroute-backup`.
- Расширение проверяет правила для HTTPS на TCP 443. В «Проверить адрес» появилась подсказка указать браузер, чтобы учесть правила для программы.
