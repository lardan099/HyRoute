HyRoute 1.1.0 — пошаговая настройка и простой режим

Пошаговая настройка:
- При первом запуске HyRoute проводит по шагам: установка в Program Files, сервер, проверка, выбор того, что пускать через VPN, запуск с Windows, включение. Каждый шаг объясняется простыми словами.
- Правила собираются по шагам с объяснениями: только выбранное через VPN или всё, кроме выбранного; сервисы (нейросети, Telegram, YouTube, Discord и другие), программы, сайты, блокировка рекламы, сервер для каждого пункта и подстраховка другими серверами. В конце видно, что получилось.
- Та же пошаговая настройка правил — кнопка «Пошагово» на странице «Правила».
- Одно поле и для ссылки на сервер (hysteria2://), и для ссылки подписки (https://). На ссылки VLESS, VMess и других протоколов HyRoute объясняет, что нужна ссылка Hysteria 2.
- Проверка сервера говорит понятно: работает ли он, какой адрес увидят сайты, быстрый ли он, и что делать, если не подключается.
- Настройку можно пропустить и пройти заново: «Настройки → Режим интерфейса».

Простой режим:
- Новая установка открывается в простом режиме: в меню только главное, на страницах подсказки, которые можно закрыть.
- Локальные прокси, списки, соединения, журнал, правила текстом, базы правил и тонкие настройки — в режиме «Для опытных» («Настройки → Режим интерфейса»).
- Если серверы уже были добавлены, HyRoute после обновления остаётся в полном режиме.
